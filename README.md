# Entity Framework Core Systems & Relationships - DEPI

### 1. Projects Implementation
The repository contains three complete .NET 5 console applications (`EcommerceSystem`, `HealthCareSystem`, and `LibrarySystem`) implementing:
- Code-First Entity Framework Core mappings and DbContext configurations.
- One-to-Many and Many-to-Many relationships through explicit junction tables with composite primary keys.
- Fluent API configurations (`OnModelCreating`, `DeleteBehavior.Restrict`).
